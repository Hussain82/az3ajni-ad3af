# أزعجني أضعف | Az3ajni Ad3af v4

## 📁 ملفات المشروع

| الملف | الوصف |
|-------|-------|
| `Az3ajni_Ad3af_v4.html` | التطبيق الرئيسي |
| `manifest.json` | ملف PWA (مطلوب للـ APK) |
| `sw.js` | Service Worker (للـ Offline) |
| `icons/` | أيقونات بجميع الأحجام |

## 🚀 رفع على GitHub Pages

1. ارفع **جميع** هذه الملفات للمستودع
2. تأكد أن `manifest.json` و `sw.js` في نفس المجلد مع HTML
3. فعّل GitHub Pages من Settings
